# Calculator & Unit Converter

A web-based application that combines a calculator and a multi-category unit converter, built to practice and strengthen front-end development skills using HTML, CSS, and JavaScript.

## Features

### Calculator
- Basic arithmetic operations (addition, subtraction, multiplication, division)
- Clear display and delete last character functionality
- Real-time input and result evaluation
- Error handling for invalid expressions

### Unit Converter
Supports multiple conversion categories:

- Length (millimetres, meters, miles, etc.)
- Weight (grams, kilograms, pounds, etc.)
- Temperature (Celsius, Fahrenheit, Kelvin)
- Time (seconds, minutes, hours, etc.)
- Area (square meters, hectares, acres, etc.)
- Volume (liters, cubic meters, gallons, etc.)

### General Functionality
- Toggle/switch between calculator and unit converter within the same interface
- Swap units instantly in converter mode
- Input validation and error handling

## Technologies Used

- HTML5
- CSS3
- JavaScript (DOM manipulation, event handling, conditional logic)

## Purpose

This project was created to gain hands-on experience building interactive front-end applications and managing multiple features within a single interface.

## What I Learned

- Handling dynamic UI updates and application state (switching between modes)
- Structuring JavaScript for multi-feature functionality
- Implementing unit conversion logic using consistent base units
- Validating user input and handling edge cases
- Improving code organization and readability
